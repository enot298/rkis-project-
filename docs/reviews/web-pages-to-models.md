# Веб: страница → модель → поля → способ получения

Составляет ФР (Криницын В.). Источник — требования REQ-WEB-001…006 (блок 1).

| Страница | Модель | Поля / данные | Способ получения |
|---|---|---|---|
| REQ-WEB-001 Список заказов | Order | номер (`id`), дата, статус, сумма | атрибуты |
| | Order → Client | имя клиента | связанный объект `order.client.name` (`select_related`) |
| | Order | фильтры по дате и статусу, сортировка, пагинация | индексы `idx_order_date`, `idx_order_status`; запрос |
| | Order | число позиций | `Order.items_count` или аннотация `Count("items")` |
| REQ-WEB-002 Детали заказа | Order | все поля, заметки, причина отмены, версия | атрибуты |
| | OrderItem → Product | название, количество, цена, сумма по позиции | связанные объекты, `OrderItem.line_total` |
| | Payment | способ, статус, сумма, дата оплаты | `order.payment` (может отсутствовать) |
| | Order | история изменений | **нет модели** (план: блок 6) |
| REQ-WEB-003 Создание | Client | выпадающий список клиентов | `Client.__str__` (имя) |
| | Product | список товаров, цена, остаток | `Product.price`, `stock_quantity` |
| | Order | дата по умолчанию сегодня | `default=timezone.localdate` |
| REQ-WEB-004 Редактирование | Order | можно ли редактировать | `Order.is_editable` (свойство) |
| REQ-WEB-005 Отмена | Order | причина отмены | `cancel_reason` |
| REQ-WEB-006 Дашборд | Order | количество заказов за период, суммы, распределение по статусам | агрегаты: `Count`, `Sum("total_amount")`, группировка по `status` |
| | Order | «ждут подтверждения» | `filter(needs_approval=True)` |

## Значения, которые фронтенд не считает сам

| Значение | Где живёт | Статус |
|---|---|---|
| Сумма по позиции | `OrderItem.line_total` | реализовано |
| Сумма заказа | `Order.total_amount` (кеш) и `calculate_total()` | реализовано |
| Нужно ли подтверждение | `Order.needs_approval` | реализовано |
| Можно ли редактировать | `Order.is_editable` | реализовано |
| Сеанс истёк | `Session.is_expired` | реализовано |
| Полное имя пользователя | `User.get_full_name()` (пока логин) | реализовано (поля «имя» в схеме нет) |
| «Возраст» записи | `created_at` | считать в шаблоне фильтром `timesince` |
