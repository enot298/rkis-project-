# Чек-лист №2: тестирование админки

**Версия:** 1.0 (к прогону) · **Составила:** Васильева С. (QA) · Колонка «Результат» заполняется при прогоне: `OK` или `FAIL` (при FAIL — номер бага в `tests/bug-reports/`).

## Подготовка

```
cd django
python manage.py migrate
python manage.py loaddata 01_accounts 02_customers 03_catalog 04_orders
python manage.py runserver
```

Админка: http://127.0.0.1:8000/admin/. Вход: `admin` / `Test12345!` (фикстуры). Загрузка фикстур — **только на чистую базу**. Окружение: см. `tests/test-plans/environment.md`. Описание записей — `tests/fixtures/README.md`.

## A-PAG. Пагинация (граничные случаи)

Для проверки нужно больше 25 записей. Создать 26 клиентов в консоли (`python manage.py shell`):

```python
from apps.customers.models import Client
for i in range(26):
    Client.objects.create(name=f"Тест {i:02d}", phone="+79000000000")
```

| № | Шаг | Ожидаемый результат | Результат |
|---|---|---|---|
| A-PAG-01 | Список клиентов | Страница 1: 25 записей; ссылка на страницу 2 | |
| A-PAG-02 | Страница 2 | Остальные записи | |
| A-PAG-03 | Фильтр/поиск + переход между страницами | Выбор сохраняется | |
| A-PAG-04 | Страница за пределами диапазона (`?p=99`) | Страница не ломается | |
